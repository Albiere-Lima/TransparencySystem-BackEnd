# Portal de Transparência Estudantil - API Backend

API RESTful desenvolvida com Spring Boot para gerenciamento e exibição transparente de despesas financeiras de entidades estudantis. Integrada ao PostgreSQL via Docker Compose e projetada para integração com front-end em React e TypeScript.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java 17+
* **Framework:** Spring Boot 3+ (Spring Data JPA, Spring Web)
* **Banco de Dados:** PostgreSQL
* **Containerização:** Docker & Docker Compose
* **Gerenciador de Dependências:** Maven

## 📋 Pré-requisitos

Certifique-se de ter instalado em sua máquina Linux:

* **Docker & Docker Compose**
* **JDK 17+** (Opcional se rodar exclusivamente via Docker, necessário para compilação local)
* **Git**
